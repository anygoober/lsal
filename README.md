`lsal` makes the linux command `ls -al` interactive.

![preview](./assets/preview)

## Keybinding
- `Up` / `k`: Move up
- `Down` / `j`: Move down
- `Ctrl-C`: Select & Copy
- `Ctrl-X`: Cut
- `Ctrl-V`: Paste
- `Space`: Select highlighted
- `u`: Clear selected
- `r`: Reload (refresh)
- `.`: Show hidden items
- `!`: Open terminal in this directory
- `q`: Quit
